# Ajouter les enregistrements

Déposez ici vos cinq MP3, nommés `piste-1.mp3` à `piste-5.mp3`.
Dans `script.js`, remplacez la ligne `const sources = ...` par :

```js
const sources = {
  1: "audio/piste-1.mp3",
  2: "audio/piste-2.mp3",
  3: "audio/piste-3.mp3",
  4: "audio/piste-4.mp3",
  5: "audio/piste-5.mp3"
};
```

Vous pouvez activer une seule piste à la fois, en laissant les autres à `null`.
Utilisez des enregistrements que vous avez le droit de diffuser.
